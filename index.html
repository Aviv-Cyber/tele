App Feature Documentation

Complete interactive user guide & keyboard shortcuts

Audio Playback & Voice Notes

  • Web Audio Synthesizer: Voice message bubbles play back real audio tones generated with the browser's Web Audio API.
  • Equalizer Wave Visualization: Dynamic pulse animations sync with live voice note playback.
  • Voice Note Creation: Tap the microphone icon in the message input bar to record and attach new voice messages.
  • Sound Effects Synthesizer: UI clicks and message send/receive produce dual-frequency audio pings.

Keyboard Shortcuts & Controls

  • Esc Key: Instantly close open popovers, context menus, and backdrop modal dialogs.
  • Ctrl + K / Cmd + K: Jump directly to the chat list search input from anywhere.
  • Enter: Send active input message text immediately.

Interactive Popovers & Actions

  • Context Menu & Quick Reactions: Right-click (or tap & hold) any message bubble to trigger quick emoji reactions (👍, ❤️, 🔥, 😂, 😮, 💩).
  • Pin Message: Pin important messages to top header banners.
  • Media Lightbox Viewer: Click any image message to expand into an animated backdrop-blurred fullscreen image modal.
  • In-Chat Search: Search keyword text directly within active chat threads using the header search icon.
  • Folder Filters: Filter chats by All Chats, Personal, Groups, Channels, and Bots.
